Illustrative Case Study Application
===================================

Electronic supplement to the *Illustrative Case Study Application for OQ-VMTK* section of the EQ Spectra paper. Walks through the full workflow in a single notebook: calibration of an MDOF stick-and-mass model from an SDOF capacity curve (``calibration``), model compilation, modal and static pushover verification (``modeller``), Modified Cloud Analysis, fragility and vulnerability function derivation (``postprocessor``), and visualisation of every stage (``plotter``).

`Open notebook on GitHub <https://github.com/GEMScienceTools/oq-vmtk/blob/main/demos/EQSpectraExample/EQSpectraExample.ipynb>`_
