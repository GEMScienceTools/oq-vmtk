# Illustrative Case Study Application for OQ-VMTK

This notebook is the electronic supplement to the example provided in the *Illustrative Case Study Application for OQ-VMTK* section of the EQ Spectra paper. It calibrates an MDOF stick-and-mass model from an SDOF capacity curve, verifies it through modal and static pushover analyses, runs Modified Cloud Analysis, and derives fragility and vulnerability functions using the `calibration`, `modeller`, `postprocessor` and `plotter` modules.
