# Storey Loss Function Generation Demo

This Jupyter Notebook demonstrates how to generate and visualize storey loss functions (SLFs) from component inventory data. The workflow involves reading inventory files that define damageable components, including their quantities, fragility parameters, and repair costs. Using the `slfgenerator` module from oq-vmtk, the data are processed into SLFs -- the expected storey loss ratio vs. EDP, with its Monte Carlo dispersion and 16th/50th/84th percentiles -- which are then visualized with the `plotter` module. The bundled inventories follow the FEMA P-58 format and include one example of each damage state hierarchy: sequential, mutually exclusive (`MutEx`), sequential then mutually exclusive, and simultaneous (`Simul`), set by the `DS Hierarchy` and `DSx, Probability` columns. The notebook walks through two examples for both drift- and acceleration-sensitive components: Example A (components damaged independently) and Example B (components coupled via a `correlation_tree`).
